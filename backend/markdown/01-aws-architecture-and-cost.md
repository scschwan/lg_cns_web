## 네트워크 아키텍처 (VPC)

### VPC 구성

```
VPC CIDR: 10.0.0.0/16

┌────────────────────────── VPC (10.0.0.0/16) ──────────────────────────┐
│                                                                         │
│  ┌───────────────────── Public Subnet (10.0.1.0/24) ────────────────┐ │
│  │                                                                   │ │
│  │  ┌──────────────────┐       ┌──────────────────┐                │ │
│  │  │  ALB             │       │  NAT Gateway     │                │ │
│  │  │  (Internet 연결) │       │  (Outbound 전용) │                │ │
│  │  └──────────────────┘       └──────────────────┘                │ │
│  │                                                                   │ │
│  └───────────────────────────────────────────────────────────────────┘ │
│                                   │                                     │
│  ┌───────────────────── Private Subnet (10.0.2.0/24) ───────────────┐ │
│  │                               │                                   │ │
│  │  ┌────────────────┐   ┌──────────────┐   ┌──────────────────┐  │ │
│  │  │  ECS Fargate   │   │  DocumentDB  │   │  ElastiCache     │  │ │
│  │  │  (Spring Boot) │   │  (MongoDB)   │   │  (Redis)         │  │ │
│  │  └────────────────┘   └──────────────┘   └──────────────────┘  │ │
│  │                                                                   │ │
│  └───────────────────────────────────────────────────────────────────┘ │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 서브넷 분리 이유

```
Public Subnet (인터넷 연결):
✅ ALB: 외부 요청 수신
✅ NAT Gateway: Private Subnet의 아웃바운드 제공

Private Subnet (외부 차단):
✅ ECS Fargate: API 서버 (보안)
✅ DocumentDB: 데이터베이스 (보안)
✅ Redis: 캐시 서버 (보안)

보안 이점:
- 데이터베이스 직접 접근 불가
- 모든 트래픽은 ALB 경유
```

## 보안 구성

### Security Groups

```
SG-ALB (Application Load Balancer):
─────────────────────────────────────────
인바운드:
  - 80 (HTTP): 0.0.0.0/0 (전체 허용)
  - 443 (HTTPS): 0.0.0.0/0 (전체 허용)

아웃바운드:
  - 8080: SG-ECS (Fargate로만)


SG-ECS (ECS Fargate):
─────────────────────────────────────────
인바운드:
  - 8080: SG-ALB (ALB에서만)

아웃바운드:
  - 27017: SG-DocumentDB (MongoDB)
  - 6379: SG-Redis (Redis)
  - 443: 0.0.0.0/0 (AWS 서비스 호출)


SG-DocumentDB (MongoDB):
─────────────────────────────────────────
인바운드:
  - 27017: SG-ECS (Fargate에서만)
  - 27017: SG-Lambda (Lambda에서만)

아웃바운드:
  - 차단 (필요 없음)


SG-Redis (ElastiCache):
─────────────────────────────────────────
인바운드:
  - 6379: SG-ECS (Fargate에서만)

아웃바운드:
  - 차단 (필요 없음)
```

### IAM 역할

```
ECS Task Execution Role:
- ECR 이미지 pull 권한
- CloudWatch 로그 쓰기 권한

ECS Task Role:
- S3 읽기/쓰기 (Excel 파일)
- SQS 메시지 발행
- DocumentDB 접근
- Redis 접근

Lambda Execution Role:
- S3 읽기 (Excel 다운로드)
- DocumentDB 쓰기
- Redis 쓰기
- CloudWatch 로그
```

## 예산 최적화 전략

### 비용 절감 방법

```
1. Fargate Spot 인스턴스
─────────────────────────────────────────
일반: $36/월
Spot: $18/월 (50% 할당)
절약: $18/월

주의: 중단 가능성 있음 (비권장)


2. Reserved Instance (예약 인스턴스)
─────────────────────────────────────────
DocumentDB 1년 예약:
- 일반: $73/월
- 예약: $50/월 (31% 할인)
- 절약: $23/월 × 12 = $276/년


3. S3 Intelligent-Tiering
─────────────────────────────────────────
자동으로 자주 안 쓰는 파일을 저렴한 계층으로 이동
Excel 파일 7일 후 자동 삭제로 이미 최적화


4. CloudWatch 로그 보존 기간 단축
─────────────────────────────────────────
기본 무기한 → 30일로 설정
월 $2 절약


5. Lambda 메모리 최적화
─────────────────────────────────────────
1024MB → 512MB로 조정 가능 시
월 $7.5 절약
```
