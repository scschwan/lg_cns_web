# 계정원장 분석 Tool 개선사항 조치 결과 보고

> **일자**: 2026-04-03
> **작성**: 개발팀

---

## 1. 계정원장 분석

### 1-1. Multi File 업로드
| 항목 | 내용 |
|------|------|
| **요청** | 생성된 세션 목록에 세로 스크롤바 추가 필요 |
| **조치** | 검토 중 (추후 반영 예정) |

---

### 1-2. Start Analysis
| 항목 | 내용 |
|------|------|
| **요청** | 필수 항목 설정 세목 열에 "세목" 컬럼이 자동 선택되도록 변경 (현재 "목"으로 매핑됨) |
| **조치** | 완료. 원본 데이터에 "세목" 컬럼이 존재할 경우 해당 컬럼이 우선 매핑되도록 수정 |

| 항목 | 내용 |
|------|------|
| **요청** | 원본 데이터 창 크기 조절 기능 (크기 조절이 안되면 가공 데이터와 반반) |
| **조치** | 완료. 원본/가공 데이터 테이블을 50:50 비율로 조정하고, 드래그로 높이 조절이 가능하도록 개선. 원본 데이터 영역을 접기/펼치기할 수 있는 기능도 추가 |

---

### 1-3. Preprocessing (전처리)
| 항목 | 내용 |
|------|------|
| **요청** | 구분자/불용어 설정을 사용자 계정 내 모든 세션에 동일하게 적용 (추가/제거 기억, 모든 프로젝트) |
| **조치** | 완료. "현재 설정을 사용자 기본값으로 저장" 버튼을 추가하여, 저장된 구분자/불용어 설정이 이후 생성되는 모든 프로젝트의 새 세션에 기본값으로 자동 적용되도록 개선 |

---

### 1-4. Data Transform (데이터 변환)
| 항목 | 내용 |
|------|------|
| **요청** | 원본 데이터 크기 조절 기능 |
| **조치** | 완료. Start Analysis와 동일하게 원본/검색결과 테이블 50:50 비율 + 드래그 높이 조절 + 접기/펼치기 기능 적용 |

---

### 1-5. Clustering (클러스터링)
| 항목 | 내용 |
|------|------|
| **요청** | 추천 키워드가 프로젝트 내 모든 사용자에게 동일하게 공유되어야 함 |
| **조치** | 완료. 추천 키워드 계층 구조를 세션 단위에서 프로젝트 단위로 변경하여, 동일 프로젝트 내 모든 사용자에게 동일한 추천 키워드가 표시되도록 수정 |

| 항목 | 내용 |
|------|------|
| **요청** | 추천 키워드/공급업체 클릭 시 미병합 클러스터에 연동되어 나오지 않음 |
| **조치** | 기존 구현 완료. 각 키워드/공급업체 항목 옆의 **"자세히" 버튼**을 클릭하시면 해당 항목의 클러스터가 조회됩니다 |

| 항목 | 내용 |
|------|------|
| **요청** | 추가 병합 시 수정했던 클러스터명이 다시 바뀌는 현상 |
| **조치** | 완료. 추가 병합 시 기존에 사용자가 지정한 클러스터명이 그대로 유지되도록 수정 |

| 항목 | 내용 |
|------|------|
| **요청** | 병합 버튼 클릭 시 바로 임의 이름으로 등록됨 → 클러스터명 입력 팝업 후 등록 희망 |
| **조치** | 완료. 병합 버튼 클릭 시 클러스터명을 입력하는 팝업이 표시되며, 이름 입력 후 확인 버튼을 눌러야 등록되도록 변경. 자동 클러스터링(키워드/공급업체 기반)의 경우에도 항목별로 개별 클러스터명을 지정할 수 있도록 개선 |

## 2. 대시보드
