## 2. 개발 우선순위 및 단계

```
Phase 0: 인증 및 프로젝트 관리 (최우선) ✅ 완료
   ├─ 사용자 로그인/회원가입
   ├─ JWT 인증
   ├─ 프로젝트 생성/관리
   ├─ 프로젝트 공유 및 권한 관리
   └─ 프로젝트별 세션 격리

Phase 1: 대용량 파일 업로드 (우선) ✅ 완료
   ├─ S3 Presigned URL 업로드
   ├─ SQS 메시지 큐
   ├─ Lambda Coordinator (파일 분석)
   ├─ Lambda Worker (병렬 파싱)
   └─ 진행률 추적 (Redis)

Phase 2: 비즈니스 로직 구현 (순차) ⭐ 현재 작업 중
   ├─ Step 1: Multi File Upload (세션 생성, 계정명 파티션)
   ├─ Step 2: File Load (Excel → raw_data)
   ├─ Step 3: Preprocessing (키워드 추출)
   ├─ Step 4: Data Transform (집계, 그룹핑)
   ├─ Step 5: Clustering (사용자 기반 클러스터링)
   ├─ Step 6: Export (Excel 내보내기 + 세션 완료)
   └─ Step 7: Detail Clustering (세부 클러스터링)

Phase 3: UI 구현
   ├─ React 프로젝트 구조
   ├─ C# WinForms UI 재해석
   ├─ 반응형 템플릿 적용
   └─ 7단계 프로세스 화면
```

    .GetByClusterNumbersAsync(clusterIds);

var mergedKeywords = clustersToMerge
    .SelectMany(c => c.Keywords)
    .Distinct()
    .ToList();

    .SelectMany(c => c.DataIndices)
    .Distinct()
    .ToList();

var newCluster = new ClusteringResultDocument
{

    ClusterId = newClusterNumber,
    ClusterName = combinedClusterName,

    Count = mergedDataIndices.Count,
    TotalAmount = totalAmount,
    DataIndices = mergedDataIndices
